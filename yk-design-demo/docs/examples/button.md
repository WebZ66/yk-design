## Attributes



| 参数     | 说明         | 类型    | 可选值                                             | 默认值  |
| -------- | ------------ | ------- | -------------------------------------------------- | ------- |
| type     | 按钮类型     | string  | primary / success / warning / danger / info / text | --      |
| size     | 按钮尺寸     | string  | s / m / l /xl                                      | s       |
| shape    | 按钮形状     | string  | default / round /  circle / square                 | default |
| loading  | 是否加载中   | boolean | true / false                                       | false   |
| disabled | 是否无法选中 | boolean | true / false                                       | false   |
