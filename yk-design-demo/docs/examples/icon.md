# Icon 图标

基于 [fontawesome](https://fontawesome.com/search?m=free&o=r) 开源图标库提供的一系列图标

**注意：yk-design@1.0.1版本目前已废弃**~~vite-plugin-svg-icons~~

**yk-design@1.0.0版本可继续使用该插件**

## 使用方法

直接设置 `icon`属性即可(继承自 fontawesome 的所有属性)
